⚙️ End-to-End Analytical Pipeline & Technology Stack

System Design
1. Data Collection
6,800+ realistic EV records across 12 global automakers, 6 vehicle categories, and 5 battery chemistries (2019-2025).
2. SQLite & Schema
Normalized Star-Schema (Fact + 4 Dimensions), Denormalized Analytics table, and indexed views for sub-10ms response.
3. SQL Operations
Advanced analytical queries using CTEs, window functions (RANK, LAG), grouping sets, and performance benchmarks.
4. Visualization & Story
10+ unique visualizations, dynamic multi-parameter filtering, and 5-scene Tableau Story mode guiding strategic decisions.
5. Flask Integration
High-performance REST API, interactive SQL explorer, responsive UI, and Tableau embed integration.
